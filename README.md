# Ay-Vee Utopia

**A music visualizer that reads a song the way I hear it: in layers.**

▶ **Live:** https://amarnate.github.io/ayvee-utopia/

Most visualizers react to "loudness". Ay-Vee splits a song into separate layers (bass, low end, voice and harmonics, and the hits) and gives each one its own floor and ceiling. So a quiet verse still moves the picture as much as a loud chorus, and a repeating bass line reads as a pulse, not noise.

## What's in it
- **Embodiments.** Named characters (Bod-e, Wren, Gali, Zeph) that each move to the music in their own way
- **Focus.** A companion, Pelvy, gathers echoes from the song. Release them for a Focus moment; one, two or three stored echoes each release a different, bigger effect
- **Layer reading.** Four bands, each scaled to its own range, plus a bass pulse detector that finds the beat subdivision
- **The thread.** Hold Thread (or T) while the one element woven through a song plays; every time the song reaches it again, the embodiments feel it
- **Listens to what you're playing.** A browser tab (YouTube, Spotify web) or the microphone
- **Clip recorder.** Save a video of the visualizer dancing to your song, with the tab's sound
- **Lab.** Live readouts of every layer and the frame rate, for testing
- **Phone and PC layouts,** each designed on its own

## How it's made
Designed by me, built by directing Claude. I set the vision, the look and the rules, test every build on a fixed six-song test kit, and rule on how it feels. Claude writes the code. Every release is checked function by function, with frame-rate checks on the heaviest moments, before it ships.

The look is my own design language, **Frequency Realism**: a dark field, bevelled plates, circuit traces, and light that behaves like real light.

**Status:** alpha, in active development.
